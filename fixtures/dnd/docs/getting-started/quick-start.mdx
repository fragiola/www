## A draggable and a droppable

```tsx title="board.tsx"
<Draggable id="card">
    <div className="card">Card</div>
</Draggable>
<Droppable id="box" onDrop={({ draggableId }) => move(draggableId)}>
    <div className="box" />
</Droppable>
```
