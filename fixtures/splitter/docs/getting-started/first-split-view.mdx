## A group, two panels and a separator

```tsx title="workbench.tsx"
<Splitter.Group orientation="horizontal">
    <Splitter.Panel id="sidebar" defaultSize="25%">Sidebar</Splitter.Panel>
    <Splitter.Separator />
    <Splitter.Panel id="editor">Editor</Splitter.Panel>
</Splitter.Group>
```
