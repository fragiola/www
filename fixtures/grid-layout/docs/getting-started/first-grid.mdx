## A layout and its items

```tsx title="dashboard.tsx"
<GridLayout.Root defaultLayout={layout}>
    <GridLayout.Items>
        {(item) => <GridLayout.Item itemId={item.id}>{item.id}</GridLayout.Item>}
    </GridLayout.Items>
</GridLayout.Root>
```
