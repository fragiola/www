## Columns and rows

```tsx title="people.tsx"
<DataGrid.Root columns={columns} rows={people}>
    <DataGrid.Grid aria-label="People">
        <DataGrid.Header />
        <DataGrid.Body />
    </DataGrid.Grid>
</DataGrid.Root>
```
